## 1. 設計原則

### 1.1 精算とライフプランを分離する

現在の請求予定額は、`CHIHARU SATO` のAmex利用、ETC、負担率適用後の手入力費用を集めた「二人の間の精算額」であり、世帯全体の生活費ではない。ライフプランでは次の2つを別管理する。

画面ではこの精算額を二人分合計として保持し、主表示に `二人分合計 ÷ 2` の一人あたり請求予定額を表示する。端数は1円単位で四捨五入する。

- 精算台帳: 誰が立て替え、誰がいくら負担するか。
- 世帯キャッシュフロー: 二人の収入、世帯全体の支出、資産、負債がどう変化するか。

精算結果は支払者間の資金移動であり、世帯全体の純資産を増減させない。家賃・食費などの元金額だけを世帯支出へ1回計上する。

### 1.2 ストックとフローを分離する

- フロー: 収入、生活費、利息、イベント費用など、その月に発生する金額。
- ストック: 現預金、投資残高、住宅価値、ローン残高など、月末時点の残高。

投資積立は現預金から投資資産への振替であり、純資産上の支出として二重計上しない。

### 1.3 個人キャッシュフローのAmex引落額

個人資産画面では、精算画面の「請求対象Amex」と実際の口座引落額を分けて扱う。請求対象Amexは共同精算のための既存ルール（`CHIHARU SATO` とETC）を使う一方、個人キャッシュフローのAmex引落額はカード名義に関係なく全明細を合計する。ただし、前回分口座振替などの履歴行は除外する。メイン口座を指定した場合、口座全額に含まれる給料・請求額を差し引いて基礎残高を求め、残るお金へ組み込む。

```text
個人の残るお金
  = メイン口座の基礎残高
  + 自分の給料
  + 受け取る請求額
  - Amex全明細の引落額（前回振替を除く）
  - 共有費用
  - 個人支出

メイン口座の基礎残高
  = メイン口座全額 - (自分の給料 + 受け取る請求額)

メイン口座指定時の総資産
  = その他口座残高合計 + 投資評価額合計 + メイン口座の残額

投資可能額
  = floor((その他口座残高合計 + メイン口座の残額 - 手元に残す予備資金) / 1,000) × 1,000
  ※0円未満にはせず、1,000円未満の端数を切り捨てる

配分
  インカムゲイン側 = floor(投資可能額 × 80% / 1,000) × 1,000
  キャピタルゲイン側 = 投資可能額 - インカムゲイン側
  ※配分後に残る1,000円未満の端数ではなく、千円単位の残額はキャピタル側へ回す
```

## 2. 共通月次計算

月 `m` の基本計算は次の順序とする。

```text
世帯手取り収入[m]
  = 本人手取り[m] + パートナー手取り[m] + その他収入[m]

生活支出[m]
  = 家賃・住宅費[m] + 固定費[m] + 変動費[m] + 教育費[m]

月間現金収支[m]
  = 世帯手取り収入[m]
  - 生活支出[m]
  - ローン利息[m]
  - ローン元本返済[m]
  - 一時イベント費用[m]

現預金[m]
  = 現預金[m-1]
  + 月間現金収支[m]
  - 投資積立[m]
  + 投資取崩し[m]

投資残高[m]
  = 投資残高[m-1] × (1 + 年間運用率)^(1/12)
  + 投資積立[m]

純資産[m]
  = 現預金[m] + 投資残高[m] + 住宅評価額[m] - ローン残高[m]
```

物価上昇は `基準額 × (1 + 年間上昇率)^((m-1)/12)` とし、費目ごとに上昇率を設定できる形へ拡張する。

## 3. 機能・ロジックマトリクス

| 機能名 | 何が分かるか | 必要な入力 | 採用ロジック | 優先度 |
|---|---|---|---|---|
| 収入計画 | 毎月・毎年の世帯手取り | 二人の月間手取り、賞与、昇給率、休職期間 | `月収 × 昇給係数 × 稼働率 + 該当月賞与`。税額推計はせず手取りを入力 | 最優先 |
| 貯蓄残高予測 | 任意時点の現預金と純資産 | 初期現預金、収入、支出、積立 | 前月残高へ月間収支を加え、積立・元本返済を資産振替として処理 | 最優先 |
| 二人別の収入・負担 | 公平な共通費負担と各自残額 | 各自手取り、個人固定費、負担方式 | 初期値は可処分手取り比例。`(手取り−個人固定費)÷二人の可処分手取り合計` | 高 |
| ライフイベント | 結婚、引越し、出産、車などの影響 | 発生月、一時費用、継続費、終了月、負担者 | 一時費用は発生月に1回、継続費は開始月から終了月まで月次加算 | 高 |
| 緊急資金判定 | 収入停止へ何か月耐えられるか | 流動資産、必須生活費、目標月数 | `流動資産 ÷ 必須生活費月額`。目標初期値は6か月 | 高 |
| 住宅計画 | 賃貸継続と購入の資金差 | 家賃、更新料、物件価格、頭金、金利、期間、維持費 | 賃貸累計と、購入時現金流出・ローン残高・住宅評価額を比較 | 中 |
| 教育費計画 | 子どもの年齢ごとの必要額 | 誕生月、進路、学校区分、費用表 | 子どもの年齢と年度を対応させ、進路別年額を12分割して加算 | 中 |
| 退職・老後計画 | 退職後の不足額と資産寿命 | 退職年齢、年金月額、老後支出、寿命想定 | 退職後は給与を停止し、`年金−支出` の不足分を資産から取り崩す | 中 |
| 資産運用 | 積立後の投資残高と元本差 | 初期残高、月額積立、期待利回り、手数料 | 月次複利。`前月残高 × (1+実質年率)^(1/12) + 月額積立` | 中 |
| 資金不足アラート | 資金ショート時期と不足最大額 | 最低現金残高、月次予測 | 現預金が最低残高を下回る最初の月を検出し、原因イベントを併記 | 高 |

## 4. 個別ロジック

### 4.1 収入計画

- MVPでは税・社会保険を推計せず、実際の月間手取りを入力する。
- 賞与は二人それぞれに年間手取り額と発生月を1つ設定する。複数賞与・休職期間は将来拡張とする。
- 昇給は月次複利ではなく、基準月から年率を月割り換算して適用する。

### 4.2 二人別の負担

初期選択肢は次の3方式とする。

1. 50%ずつ
2. 可処分手取り比例（推奨）
3. 任意割合

```text
可処分手取り_i = max(0, 手取り_i - 個人固定費_i)
共通費負担率_i = 可処分手取り_i / 二人の可処分手取り合計
共通費負担額_i = 共通費合計 × 共通費負担率_i
```

分母が0円の場合は50%ずつとする。端数は本人側を四捨五入し、パートナー側を差額として合計一致させる。

### 4.3 緊急資金

必須生活費には住宅費、光熱通信、最低食費、保険、最低返済額を含め、旅行・娯楽・投資積立は含めない。

```text
防衛可能月数 = 現預金 / 必須生活費月額
判定: 6か月以上=安全、3〜6か月=注意、3か月未満=要対策
```

月数と判定境界は設定可能にする。

### 4.4 住宅計画

元利均等返済の月額は以下とする。月利 `r=年利/12`、返済回数 `n`、借入額 `P`。

```text
返済月額 = P × r × (1+r)^n / ((1+r)^n - 1)
```

金利0%の場合は `P/n` とする。購入側は頭金、購入諸費用、固定資産税、管理修繕を含める。比較結果は支払累計だけでなく、住宅評価額とローン残高を含む純資産でも表示する。保険、税控除、売却費、頭金の運用機会損失は初期版では含めない。

### 4.5 教育費

- 子どもごとに誕生年月と進路シナリオを持つ。
- 初期版の費用表は幼児教育、小学校、中学校、高校、大学の5段階と、公立中心・高校大学私立・私立中心の3プリセットで管理する。
- 費用表の年額へ教育費上昇率を適用し、12分割して月次へ反映する。
- 入学金と授業料は概算年額に含める。個別の入学費用はライフイベントとして追加する。

### 4.6 退職・老後

- 指定退職月で給与を停止する。
- 年金開始月から年金手取りを収入へ加える。
- 老後生活費と医療・介護予備費を支出へ加える。
- 現預金が最低残高を下回った後、投資資産を取り崩す。
- 投資を取り崩しても最低現金残高を維持できない最初の月を、資金不足月として表示する。

### 4.7 資産運用

- 初期リリースは一定利回りの決定論モデルとする。
- 表示は元本、評価益、残高を分ける。
- 名目利回りから手数料率を引いた値を運用率とする。
- 税引後計算は口座種別の要件確定後に追加する。
- 悲観・基準・楽観の利回りを比較する。モンテカルロ法は将来拡張とする。

## 5. シナリオ

| シナリオ | 収入 | 物価 | 運用 | 用途 |
|---|---|---|---|---|
| 悲観 | 入力昇給率から1ポイント減 | 入力値に1ポイント加算 | 入力利回りから2ポイント減 | 資金ショート耐性を見る |
| 基準 | 入力値どおり | 入力値どおり | 入力値どおり | 最も可能性が高い計画 |
| 楽観 | 入力昇給率へ1ポイント加算 | 入力値から0.5ポイント減 | 入力利回りへ2ポイント加算 | 上振れ余地を見る |

現在の「節約・基準・ゆとり」は1〜5年の支出幅比較として残し、ライフプランの「悲観・基準・楽観」とは別軸にする。ライフプランの3シナリオは共通入力へ上記差分を適用して即時計算する。

## 6. 実装済み範囲

1. 収入計画、初期現預金、月間収支、貯蓄残高、資金不足アラート
2. 二人別負担、ライフイベント、緊急資金判定
3. 資産運用、投資元本・運用損益、純資産
4. 賃貸と住宅購入の比較、元利均等ローン、住宅持分
5. 子どもの誕生時期と進路プリセットによる教育費
6. 退職、年金開始、老後生活費、医療介護予備費
7. 悲観・基準・楽観の3シナリオと年次・重要月表示

## 7. 初期値と利用時に置き換える項目

- 二人の月間手取り、年間賞与、現在年齢、退職年齢、年金見込額。
- 現在の現預金・投資残高、最低残したい現金。
- 世帯固定費、変動費、個人固定費、家賃。
- 共通費の負担方式。初期値は可処分手取り比例。
- 緊急資金の目標月数。初期値は6か月。
- 住宅購入、子ども、結婚・引越しなどの想定時期と金額。
- 運用利回り、手数料、物価・教育費・家賃の上昇率。

## 8. 初期版に含まないもの

- 税・社会保険の推計、休職・育休給付、複数回の賞与。
- 住宅ローン控除、団体信用生命保険、売却費、繰上返済、変動金利。
- 教育費の年度別公的統計自動更新、奨学金、各種給付。
- 投資口座別税制、確率分布、モンテカルロ分析。
- 法律・税務・金融上の助言。
